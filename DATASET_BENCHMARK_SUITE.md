# BYG v4.6 Real Dataset Benchmark Suite

This suite extends the v4.5 dataset benchmark smoke guard into a larger synthetic-realism benchmark for AI/dataset-like payloads.

Guard marker: `BYG_REAL_DATASET_BENCHMARK_SUITE_OK`.

Samples generated by the official harness:

- `conversation_1mb.jsonl`: 1 MB-class role/message conversation JSONL.
- `eval_1mb.jsonl`: 1 MB-class eval-result JSONL.
- `telemetry_1mb.csv`: 1 MB-class telemetry CSV.
- `prompt_archive_1mb.txt`: 1 MB-class repeated prompt archive text.
- `entropy_control_512kb.bin`: binary entropy-control sample.

Reports:

- `o\r\v46_real_dataset_benchmark_suite.csv`
- `o\r\v46_real_dataset_benchmark_suite_summary.txt`

Each row records raw size, selected BYG container size, ZIP baseline size, selected/raw ratio, ZIP/raw ratio, BYG-vs-ZIP delta percent, backend, payload submode, decision reason, compress milliseconds, extract milliseconds, diagnose schema and roundtrip status.

This does not claim universal compression superiority. It is a regression guard for the AI/dataset-focused use case: JSONL, CSV, prompt archives and entropy controls.
